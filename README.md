# SupportPilot — ИИ-помощник технической поддержки

Прототип для ShortHack (кейс СберТех, 12.09.2026).
Помощник принимает обращение пользователя (письмо или расшифровку звонка),
разбирает его через LLM, находит похожие заявки и статьи базы знаний,
а затем сам выполняет действие: создаёт заявку, готовит уточняющий вопрос
или черновик ответа. Оператор подтверждает одним кликом.

## Документы

## Правило номер один

`docs/01_CONTRACT.md` менять можно только по согласованию обоих разработчиков.
Если контракт поменялся — сказать вслух и обновить файл в ту же минуту.
