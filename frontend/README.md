# SaluteAgent — интерфейс

React, TypeScript, Vite. Рабочее место оператора первой линии поддержки.

## Запуск

```bash
npm install
npm run dev
```

Откроется на `http://localhost:5173`. Обращения к `/api` проксируются
на бэкенд, поэтому он должен быть запущен на порту 8000.

Переменных окружения нет: адрес API задан прокси в `vite.config.ts`.

## Экраны

| Экран | Что показывает |
|---|---|
| Инбокс | Очередь обращений, текст письма или расшифровки, разбор и решение |
| Заявки | Таблица заявок с фильтрами, статус меняется прямо в строке |
| Аналитика | Распределение потока и признаки массовых сбоев |

## Главный экран

Три колонки: очередь слева, обращение по центру, разбор справа.

В правой колонке сверху вниз: суть обращения с приоритетом и уверенностью,
извлечённые данные, чего не хватает, **проверка ответа на искажения**,
панель подтверждения и трасса шагов агента.

## На что смотреть в коде

| Файл | Отвечает за |
|---|---|
| `src/components/Verification.tsx` | Вердикт проверки, показатели, разбор по утверждениям |
| `src/components/AgentTrace.tsx` | Шаги агента, шаги модели помечены отдельно |
| `src/components/ActionPanel.tsx` | Подтверждение человеком, правка перед отправкой |
| `src/components/Passages.tsx` | Фрагменты базы знаний, на которые ссылается ответ |
| `src/api/client.ts` | Единственное место, где происходят сетевые вызовы |
| `src/types.ts` | Типы, повторяют формы из `docs/01_CONTRACT.md` |

## Состояние в шапке

Справа сверху видны два признака: каким поиском работает база знаний
и на какой модели работает помощник. Жёлтая плашка «Работает на заглушке»
означает, что ключ модели не подключён и разбор идёт по ключевым словам.
Она нужна, чтобы демонстрационный режим нельзя было принять за настоящий.
