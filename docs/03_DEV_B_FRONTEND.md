# Разработчик B — фронтенд

Ты отвечаешь за всё, что лежит в папке `frontend/`. Файлы из `backend/` не трогаешь никогда.
Перед стартом прочитай `docs/01_CONTRACT.md` целиком, особенно раздел 4.

**Главное правило первых трёх часов: ты не ждёшь бэкенд ни минуты.**
Весь интерфейс пишется поверх слоя моков, который отдаёт ровно те же объекты, что и настоящий API.
Переключение на живой бэкенд — одна переменная в `.env`.

## Как работать с Claude Code

Запусти вторую копию Claude в корне проекта. Контекст перед началом:

```
Прочитай docs/01_CONTRACT.md полностью. Это контракт проекта, формы объектов
и имена полей менять нельзя. Я разработчик фронтенда, работаю только в папке frontend/.
Папку backend/ не трогай.
```

Дальше промпты по одному, с проверкой после каждого. Коммить часто.

## Внешний вид

Тёмная тема, она выигрышнее смотрится на проекторе и совпадает со стилем хакатона.

```css
:root {
  --bg: #0f1117;
  --surface: #171a23;
  --surface-2: #1f2430;
  --border: #2a2f3d;
  --text: #e6e8ee;
  --muted: #9aa1b1;
  --accent: #7c5cff;
  --p1: #ff5c5c;
  --p2: #ff9f43;
  --p3: #4c9aff;
  --p4: #8e97a8;
  --ok: #35c77a;
  --warn: #ffcc4d;
}
```

Шрифт системный: `-apple-system, "Segoe UI", Roboto, sans-serif`. Никаких библиотек компонентов,
никакого Tailwind. Один `styles.css`, обычные классы. Скругления 12 пикселей, отступы кратны 4.

Главный экран — три колонки: очередь обращений 320 пикселей, текст обращения гибкая ширина,
панель разбора 420 пикселей. На экране уже 1100 пикселей третья колонка уезжает под вторую.

```

## Такт 3 (12:40–14:40). Действия и подключение к бэкенду

### Промпт B6

```
Сделай панель действия.

массив tickets и массив outbox.

Для create_ticket рисуй карточку заявки: ключ SD-XXXX крупно, заголовок, описание,
метки категории, приоритета и команды. Метки приоритета, категории и команды

которое можно редактировать. Поле растёт по содержимому.

Подтверждение вызывает applyDecision с decision='edit', если оператор что-то менял,
иначе 'confirm', и передаёт overrides и edited_body.
Отклонение вызывает applyDecision с decision='reject'.

После успешного применения покажи зелёную плашку «Заявка SD-1013 передана
в сетевую команду» и обнови список обращений: статус обработанного должен смениться.

- [ ] Список обращений загружается меньше чем за секунду.
- [ ] Кнопка «Разобрать» показывает скелетон, а не замерший экран.

- [ ] Трасса агента разворачивается и в ней видно, где работала модель, а где код.
- [ ] Подтверждение действия меняет состояние на экране без перезагрузки страницы.
- [ ] Жёлтая плашка «Работает на заглушке» появляется, когда бэкенд в режиме заглушки.
- [ ] Форма нового обращения работает: вставляем текст, получаем разбор.
- [ ] Ни один экран не падает при пустых данных.
